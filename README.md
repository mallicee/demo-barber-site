# Demo Barber — демо-лендинг барбершопа

Демо-сайт вымышленного барбершопа «Demo Barber» для портфолио. Пара к Telegram-боту для записи в этот же барбершоп.

**Стек:** чистые HTML, CSS и JavaScript — без фреймворков и сборки. Работает на GitHub Pages.

## Что есть на сайте

- Шапка с меню (на телефоне — «бургер»)
- Первый экран с кнопкой «Записаться»
- Услуги и цены
- Почему мы
- Мастера (3 вымышленных мастера)
- Отзывы с пометкой «демо-отзывы»
- Форма заявки с проверкой полей (демо: никуда не отправляется)
- Частые вопросы (аккордеон)
- Контакты, часы работы, схема проезда
- Подвал

Все иконки и иллюстрации нарисованы в SVG, чужих фотографий нет. Анимации появления при прокрутке, адаптивная вёрстка под телефон, планшет и компьютер.

## Ссылка на Telegram-бота

Откройте `script.js` и замените `ИМЯ_БОТА` в самом верху файла:

```js
const BOT_LINK = "https://t.me/ИМЯ_БОТА";
```

## Структура

```
index.html   — разметка страницы
style.css    — стили и адаптивность
script.js    — меню, анимации, аккордеон, форма
```

## Запуск

Просто откройте `index.html` в браузере двойным щелчком.
